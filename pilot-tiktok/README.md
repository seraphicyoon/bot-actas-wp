# Piloto TikTok (Windows, sesión separada)
No ejecutar en el VPS ni vincular el WhatsApp de producción. No usa index.js, SQLite, config.json ni los datos del bot. Instalar yt-dlp oficial y Node/npm. En CMD dentro de pilot-tiktok: npm install, npm test, npm start. Escanear con el número secundario. Enviar el código .tiktok on PIN que muestra el CMD desde otro número en un grupo de pruebas o chat privado. Solo ese chat se activa; .tiktok off lo pausa; al reiniciar hay que activar de nuevo. Nunca compartir la carpeta sesion_tiktok_prueba. Solo descargar videos propios o autorizados, sin cookies ni evasión de restricciones. Formato sin marca preferido según metadatos; no se elimina ninguna marca ni se garantiza su ausencia. Un trabajo simultáneo, 15 MB, 90 s, 65 s de descarga, 15 s entre inicios. No integra todavía rentas ni menús del bot real.
